# Project creation artwork

Local SVG exports from Figma's Projects section (`23980:142907`), create dialog
standard (`23980:142059`) and expanded (`24010:152257`). The expanded design is
the reference for the authentication, email updates and languages sections.

The HTML working prototype is behavioral context, not design authority. In
particular, its cover editor is not added to this dialog.

`close`, `dropdown`, `guest`, `email` and `languages` retain their exported 20px
dimensions; `plus` is 16px. `civic-tomorrow` is the exact 21.1094 × 10.8325
organization artwork used inside the reference's 32px avatar. Organization
identity is data supplied by the API, never the identity used for login.
